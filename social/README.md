# social/

Генератор картинки для соцсетей (Instagram-пост 1080×1080) з поточною афішею
тижня. Не пов'язано зі збіркою сайту (build.js) — окремий інструмент,
запускається вручну коли потрібна нова картинка.

## Запуск

```bash
python3 social/generate.py
```

Результат: `social/output/afisha-<дата>.png`.

## Оновлення даних

Список подій захардкожений у `EVENTS` на початку `generate.py` — перед
запуском поправте вручну під поточну афішу на 8concert.com (назва, дата,
майданчик). Пізніше можна підключити сюди прямий фетч з Airtable, як у
build.js, якщо захочеться повної автоматизації.

## Шрифти

`social/fonts/` — Lato (Cyrillic-safe заміна DM Sans/Inter з сайту) та
DejaVu Serif Italic (заміна Cormorant Garamond). Шрифти закомічені в git,
щоб скрипт працював без залежності від того, що встановлено в системі.
